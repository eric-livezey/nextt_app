# NextT App
This is the repository for the official app for [NextT](https://github.com/mLucas55/NextT).
## Structure
All relevant code is in the [lib](lib) folder. Below is a summary of each file.
- [main.dart](lib/main.dart) - The main entry point for the program.
- [home.dart](lib/pages/home.dart) - Home page/stops page widget.
- [map.dart](lib/map.dart) - Map page widget.
- [favorites.dart](lib/pages/favorites.dart) - Favorites page widget.
- [settings.dart](lib/pages/settings.dart) - Settings page widget.
- [stop_sheet.dart](lib/stop_sheet.dart) - Stop sheet widget for live predictions.
- [animated_marker.dart](lib/animated_marker.dart) - Animated marker widget for the map.
- [duration_tile.dart](lib/duration_tile.dart) - Widget which shows the live duration for predictions.
- [device-storage-services.dart](lib/device-storage-services.dart) - Handles storage for favorites.
- [t_stops.dart](lib/t_stops.dart) - A list of hard coded stops for the home page.
- [stream.dart](lib/stream.dart) - Class and logic for steaming events for the backend.
- [api.dart](lib/api.dart) - API types for streamed resources.
